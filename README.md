# TaskFlow Agile System

Sistema de gerenciamento de tarefas desenvolvido utilizando conceitos de Engenharia de Software, metodologias ágeis e integração contínua.

## Tecnologias utilizadas

- Python
- Pytest
- GitHub Actions
- GitHub Projects

## Funcionalidades

- CRUD de tarefas
- Testes automatizados
- Integração contínua
- Organização ágil com Kanban

## Como executar

```bash
pip install -r requirements.txt
python src/app.py
