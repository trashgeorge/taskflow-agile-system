# TaskFlow Agile System

Sistema de gerenciamento de tarefas desenvolvido utilizando conceitos de Engenharia de Software, metodologias ágeis e integração contínua.

## Tecnologias utilizadas

- Python
- Pytest
- GitHub Actions
- GitHub Projects

## Funcionalidades

- CRUD de tarefas
- Testes automatizados
- Integração contínua
- Organização ágil com Kanban

## Como executar

```bash
pip install -r requirements.txt
python src/app.py

## Objetivo do projeto

Auxiliar equipes ágeis no gerenciamento de tarefas.

## Metodologia Ágil

O projeto utiliza Kanban e práticas inspiradas em Scrum.
test: melhoria na documentação dos testes

## Controle de Qualidade

Os testes automatizados garantem maior confiabilidade ao sistema.
ci: documentação da integração contínua

## Mudança de Escopo

Durante o desenvolvimento foi identificada a necessidade de implementar prioridade nas tarefas.

Inicialmente o sistema apenas cadastrava tarefas simples, porém a equipe percebeu que seria importante classificar tarefas entre:

- Alta
- Média
- Baixa

Essa alteração melhorou a organização e o controle das atividades do sistema.
